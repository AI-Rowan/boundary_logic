# Plan: Add bl_local$bl_counterfactual (original-scale counterfactual object)

Date created: 2026-06-16
Date last edited: 2026-06-16

## Context

`bl_find_local_cf()` already computes the boundary counterfactual and stores it as
`bl_local$B_x` (a one-row data frame of feature values in **model/standardised** units) with
`bl_local$B_pred` (probability at the boundary). After the recent scaling work,
`bl_local$bl_target` prints the *observed* point in original (raw) units. The user wants the
symmetric companion: a `bl_local$bl_counterfactual` object that, like `bl_target`, prints the
counterfactual in the original scale.

Per the user's decision, `bl_counterfactual` **mirrors `bl_target` exactly**: it stores the
values in model units plus the `scaling`, and its `print` method converts to raw units at
display time (consistent with `bl_target`, `print.bl_shapley`, etc.). No new computation --
it just packages the already-computed `B_x`/`B_z`/`B_pred`.

## Design

### New S3 object: class `"bl_counterfactual"` (mirrors `"bl_target"`)
Built inside `bl_find_local_cf()` (`R/local_cf.R`) only when `solution_found`; `NULL`
otherwise. Fields parallel `bl_target` (`x_obs`/`z_obs`/`pred_prob`/`pred_class`/`scaling`):

```r
.make_bl_counterfactual <- function(best_result, bl_result) {
  structure(
    list(
      x_cf       = best_result$B_x,                              # 1-row df, model units (<-> x_obs)
      z_cf       = best_result$B_z,                              # 1x2 rotated Z      (<-> z_obs)
      pred_prob  = best_result$B_pred,                           # boundary probability
      pred_class = as.integer(best_result$B_pred >= bl_result$cutoff),
      scaling    = bl_result$scaling                             # display-only raw-unit scaling
    ),
    class = "bl_counterfactual"
  )
}
```
A small private helper beside the other `local_cf.R` internals. `best_result`, `bl_result`,
and `cutoff` are all in scope at the `bl_find_local_cf()` return (`best_result` built at
~594-613; `cutoff <- bl_result$cutoff` at ~385).

### Wire into the `bl_local_result` return (`R/local_cf.R` ~661-676)
Add to the `list(...)` block of the `structure()`:
```r
bl_counterfactual = if (solution_found) .make_bl_counterfactual(best_result, bl_result) else NULL,
```

### New `print.bl_counterfactual()` (mirror `print.bl_target()`, `R/local_cf.R`)
```r
print.bl_counterfactual <- function(x, ...) {
  cat("-- bl_counterfactual --\n")
  cat(sprintf("  Boundary prob  : %.4f\n", x$pred_prob))
  cat(sprintf("  Predicted class: %d\n",   x$pred_class))
  unit_note <- if (!is.null(x$scaling)) " (raw units)" else ""
  cat(sprintf("  Feature values%s :\n", unit_note))
  vals <- as.numeric(x$x_cf); nms <- names(x$x_cf)
  vals <- .scale_to_raw(vals, x$scaling, nms, "level")   # reuse existing helper
  names(vals) <- nms
  print(round(vals, 4L))
  invisible(x)
}
```
Reuses `.scale_to_raw()` (`R/data_prepare.R`, `kind = "level"` -> `value*scale + center`).
`@export` so the S3 method registers (NAMESPACE regenerated by `document()`).

### Symmetric touch: `print.bl_local_result()` (`R/local_cf.R` ~995)
After the existing `Target:` block, when `bl_counterfactual` is present, add:
```r
cat("\n  Counterfactual:\n")
print(x$bl_counterfactual)
```
So `print(bl_local)` shows target and counterfactual side by side (both raw when scaling set).

- `pred_class` is computed from `B_pred >= cutoff`; at the boundary band this reflects the
  achieved side. Documented in the roxygen.
